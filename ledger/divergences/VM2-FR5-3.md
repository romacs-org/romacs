| VM2-FR5-3 | `propertize` property keys | `Fpropertize` (`src/editfns.c:3296`) passes every key to `add_properties` (`src/textprop.c:368`), which compares keys with `EQ`, so any object is a key: `(text-properties-at 0 (propertize "a" 7 1))` is `(7 1)`, `"str"` and uninterned symbols work too, and an uninterned `face` is a different key from `face` | A property is keyed by its symbol's identity (`crates/romacs-vm/src/properties.rs` `Key`), so any symbol is a key, an uninterned one apart from the interned symbol of its name, as in GNU. Reading such a property answers nil, or `default-text-properties`' value for it. Frozen heaps and compiled Lisp units write keys by name, so `freeze` refuses a string keyed by a symbol the initial obarray does not hold, and a unit does not keep one.

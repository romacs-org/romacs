## Observable by a package

| # | mechanism | GNU | romacs | why |
|---|---|---|---|---|
| LISP-NATIVE-TRUENAME | How `file-truename` walks a local name | GNU's Lisp (`lisp/files.el`) recurses over each directory level of the name, asking `find-file-name-handler` and `file-symlink-p` at each level, splicing each link's target in and starting again, with a budget of 100 steps (COUNTER) and a cache of directory true names (PREV-DIRS) | On the outermost call, outside a handler's own call (`inhibit-file-name-operation` and `inhibit-file-name-handlers` nil), with no handler for the name made absolute (a relative name joined to `default-directory`, of which only a `~` or `~USER` prefix is expanded, so `..` climbs from a link's target as GNU's levels do), the primitive `romacs--file-truename-local` (`crates/romacs-vm/src/prims/truename.rs`) walks the name's components once, asking each joined name for its link target (readlink) and resolving `.` and `..` against the true name so far. It declines, and GNU's algorithm (`file-truename--walk`) decides the name, errors and messages included, for: more than 3 links, a walk that might spend GNU's 100 steps ((links + 1) x (components + 1), the name's and its targets' components together), a leading `//`, a link target ending in `/`, a NUL, a unibyte name with non-ASCII bytes, and a name or target that is not UTF-8. COUNTER or PREV-DIRS select GNU's algorithm too, and so does a handler claiming any name a followed link spliced in, which GNU's walk asks of each, or any handler whose `operations` property names `file-symlink-p` but not `file-truename` (one pass over `file-name-handler-alist` a call), and a multibyte name holding raw bytes. `test/romacs/lisp/file-truename-tests.el` | **Package-observable:** a file name handler is asked once for the whole name, not once per directory level, so a handler whose regexp matches only a directory part of a local name (none in Emacs's own handlers) is not asked. **Limit:** other ways a handler could virtualize links for the walk without answering `file-truename` (dispatch on other operations, state outside the alist) are not looked for: no known handler does so. Answers are pinned GNU's on the test's tree: links absolute and relative, `..` after a link, a trailing slash, `.` and doubled slashes, a missing tail, a relative name, a loop. The Lisp walk took about 3.3M instructions a call | <!-- symbols: file-truename, file-truename--walk, romacs--file-truename-local, find-file-name-handler, file-symlink-p -->

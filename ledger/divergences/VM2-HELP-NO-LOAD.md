| VM2-HELP-NO-LOAD | What C-h f, C-h v and C-h o complete over, and whether completing loads files | `help--symbol-completion-table` (`lisp/help-fns.el`) loads, as the input grows, every file whose `definition-prefixes` match it (`help--load-prefixes`, under `help-enable-completion-autoload`), offers the prefixes themselves as candidates, and lists the obarray under the prompt's predicate on every call | `lisp/completion/romacs-help-completion.el` (following help-fns.el) replaces the table: it lists the names of the symbols the predicate accepts once a prompt, until a function is defined or a file loaded, answers each key from that set and loads no file; an exact name is asked of the predicate as it is now.

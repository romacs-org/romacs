## Font selection order

| # | Scope | GNU | VM2 | Reason / evidence |
|---|---|---|---|---|
| VM2-FONT-SORT | `internal-set-font-selection-order` candidate scoring | GNU `font.c:2144-2166` scores candidate size including fixed-size fonts, DPI and average-width mismatch, with factor-of-two rejection; `xfaces.c:5850-5907` validates, stores and invalidates realized faces. | Exact validation accepts duplicates and returns nil, without changing `face-font-selection-order`. Order is stored in VM display state, published to layout, consumed by resolver ranking, and changed orders invalidate previous face publications and resolver primary/character caches. The `:height` versus other-attribute trade-off is **NOT REPRODUCED**: order is honoured only to the extent current StyleScore expresses it (width/weight/slant; Height has zero distance). | Fontconfig catalog discards non-scalable candidates and retains no size/DPI fields (`romacs-font/src/fontconfig_catalog.rs:279`); VM2 snapshot drops width/weight/slant (`romacs-vm/src/display.rs:631-636` in lane base); layout Face cannot carry them (`romacs-layout-input/src/lib.rs:23-28` in lane base); StyleScore has fixed default priority and no size term (`romacs-font/src/style.rs:148-179` in lane base). Observable font selection can therefore differ. Widening this coordinated DISPLAY substrate is deliberately deferred, not impossible. Live pinned validation witnesses: `crates/romacs-vm/tools/primh/font-selection-specs/internal-set-font-selection-order.json`; cache/ranking assertions: `romacs-font/src/resolver/tests/selection_order_test.rs`. Configured family alternatives are now copied/interned into a traced VM root, published as owned state, and successful setters always invalidate previous face publications and resolver primary/character answers. The scalable resolver still uses its existing FontsetPolicy: consuming the new GNU alternative rows is deferred, not approximated with Rust lowercase (GNU uses case-table uppercase comparison, including final-sigma equivalence and Lisp symbol identity). | <!-- symbols: internal-set-font-selection-order, internal-set-alternative-font-family-alist -->

## Observable by a package

| # | mechanism | GNU | romacs | why |
|---|---|---|---|---|
| AGENT1 | Agent sessions and their tools | GNU has no agent sessions; MCP servers for GNU Emacs are packages | `lisp/romacs/romacs-agent.el` runs a harness (Claude Code's stream-json CLI) under a supervisor of its own, `romacs-agent-host` (a transient user unit, else detached), which journals every line under `$XDG_STATE_HOME/romacs/agents/ID/`; a server attaches to it and replays the journal, so a session outlives a closed window, a server stop and a crash. The harness reaches Romacs through `romacs-mcp --reconnect`, which keeps its MCP session across server restarts: a call in flight when the server went away is answered `outcome unknown`, one made while no server listens `not executed`, a call unanswered past `romacs-agent-reply-timeout` while the editor is busy is withdrawn (`not executed` when it was still queued, else `outcome unknown`), and `romacs_call_outcome` reads the call's record in the session's call log (`calls.jsonl`, appended per state). The harness runs with the user's own configuration and permission mode; Romacs passes none and has no permission layer: an approval the harness asks for is shown in the chat (`lisp/romacs/romacs-agent-ui.el`) and the user's answer is written back. `romacs_eval` takes `budgetMs` (default `romacs-agent-eval-budget`), a deadline that quits the call at its next safepoint as C-g does and never reaches a later command; timers, which admit tool calls, run busy, so C-g quits an agent's evaluation. Edits through `romacs_buffer_edit` and `romacs_file_write` are one undo group each and keep the file's earlier content once per session | **Visible to the user** (the agents dashboard and chat buffers); Lisp sees `romacs-agent-*` and the tools | `crates/romacs-vm-gui/harness/agent_live.py` (session, survive, outcome, budget, deadline, unit, probe), `fake_harness.py` | <!-- symbols: romacs-agent-start, romacs-agent-send, romacs-agent-interrupt, romacs-agent-respond, romacs-agent-stop, romacs-agent-resume, romacs-agent-restore, romacs-agents, romacs-agent-eval-budget, romacs-agent-reply-timeout, romacs--call-deadline -->

## Observable by a package

| # | mechanism | GNU | romacs | why |
|---|---|---|---|---|
| VM2-FZF | The `fzf` completion style ships with Romacs, matched natively | GNU has no `fzf` style; its `flex` style matches subsequences and ranks by a Gotoh cost through `completion--adjust-metadata` | `lisp/romacs/romacs-fzf.el` registers `fzf` in `completion-styles-alist` (interactive sessions complete with it by default: VM2-FZF-DEFAULT). The query is fzf's extended syntax (space-separated AND terms, `'exact`, `'boundary'`, `^prefix`, `suffix$`, `^equal$`, `!negation`, `|` OR, `\ ` for a space), each term matched and scored by fzf's algorithms (`src/fzf.rs`, a port of fzf 26ff936d, MIT: FuzzyMatchV2 with V1 past fzf's slab, ExactMatchNaive/Boundary, Prefix/Suffix/EqualMatch). `romacs-fzf-smart-case` (default t): a term with an upper-case letter respects case, others ignore it; nil: `completion-ignore-case` decides; folding through the buffer's case-canon table. Matches come best first (score, then trimmed length, then table order); `completion--adjust-metadata` composes a table's own `display-sort-function`/`cycle-sort-function` with that rank as `flex`'s does. Candidates are listed as orderless lists them (`romacs-completion-candidates`, the file table cache) and copied into Rust buffers; from `romacs-fzf-parallel-threshold` (2000) candidates, scoring is split across threads with the same order. Highlighting (`romacs-fzf-match`) follows `completion-lazy-hilit-p`. Try-completion: the prefix completion when there is one, else the one match, else the input. `tests/fzf_oracle.rs` (pinned GNU: `flex` for single fuzzy terms, the terms' meaning for extended queries, boundaries, file tables); fzf's algo/pattern tests in `src/fzf.rs` | To a package: `fzf` is a style without installing anything; fzf's `--tac`, `--scheme` other than default and Latin normalisation are not offered; a typed tab stays a tab in a term (fzf turns it into a space); a pass whose completion generation advances signals `romacs-completion-stale` | Romacs offers fzf matching beside orderless; per-key scoring over thousands of candidates belongs in Rust | <!-- symbols: romacs-fzf-all-completions romacs-fzf-try-completion romacs-completion-candidates -->

## Observable by a package

| # | mechanism | GNU | romacs | why |
|---|---|---|---|---|
| VM2-FONT-BUNDLED | Where the fonts a session draws with come from | GNU ships no fonts: Fontconfig lists the system's and the user's font directories, and `emacs -Q` draws its default face in whatever the system's `monospace` resolves to. | Romacs ships its fonts in `assets/fonts` (an installation's `share/romacs/assets/fonts`): Romacs Icons for the mode line (VM2-MODE-LINE) and Iosevka 34.9.1 (the default variant, hinted; Regular, Bold, Italic, Bold Italic), the default face's family (`rlisp/romacs-startup.el`). Each process registers them at startup as Fontconfig application fonts (`crates/romacs-vm-gui/src/fonts.rs`), so they are listed beside the system's, by `font-family-list` and `list-fonts` too, and nothing is installed into a font directory. A face listed by both, as an Iosevka the system has of the same style, resolves to the bundled file: Fontconfig's listing puts registered faces first, so they win a tie. `tools/bundled_fonts.py check` verifies each file against `assets/fonts/sources.json` (upstream archive and file SHA-256). | A fresh install draws in the font Romacs's layout assumes (Iosevka's `…` and arrows are two cells, VM2-ELLIPSIS) without the user installing it, and a system Iosevka of another version does not change it. A user's own family in the default face or a fontset still wins, as any face attribute does. | <!-- symbols: font-family-list, list-fonts --> |

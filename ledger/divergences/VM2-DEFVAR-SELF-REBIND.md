## Observable by a package

| # | mechanism | GNU | romacs | why |
|---|---|---|---|---|
| VM2-DEFVAR-SELF-REBIND | `defvar` whose initial value rebinds its own variable inside a `let` | `eval.c` Fdefvar decides before evaluating the value which binding it sets: the current one when `default-boundp` is nil (a let's too), else a let-shadowed unbound toplevel binding's saved value | The compiled `defvar` (`#:vm2-defvar-boundp`, `#:vm2-defvar-set-default`, `crates/romacs-vm/src/variable_runtime.rs`) decides after the value ran: a void current binding is set, else a let shadowing an unbound toplevel value gets the saved value, else the current binding the value bound. Every other case is GNU's (`crates/romacs-vm/tests/defvar_void_let.rs`); the two that differ need the value to change its own variable's binding inside such a `let`, as `(let ((x 1)) (defvar x (progn (makunbound 'x) 5)))` does with `x` dynamically bound and unbound at toplevel (a toplevel value skips the initial value in both), where GNU leaves the let's binding void and 5 the toplevel value | **Package-observable** only to code that does that, which no known package does; deciding first would cost every `defvar` more code (a code image's restore grows from 4 objects to 7) or a field every world carries | <!-- symbols: defvar -->

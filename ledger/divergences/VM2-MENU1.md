|---|---|---|---|---|
| VM2-MENU1 | Popup menus and dialogs (`x-popup-menu`, `x-popup-dialog`) | menu.c pops a toolkit menu or dialog on a window-system frame (GTK on pinned GNU pgtk) and its own text menus on a terminal; POSITION is an event, t or ((XOFFSET YOFFSET) WINDOW), nil showing nothing; MENU a keymap, a list of keymaps or (TITLE (PANE-TITLE ITEM...)...); the value is the events leading to a keymap menu's choice, a pane menu's VALUE; dismissing quits, except after a mouse event (nil); a dialog without toolkit dialogs is a menu (emulate_dialog_with_menu) | `lisp/romacs/romacs-menu.el` keeps that contract and shows the menu with GNU's own text-menu machinery, tmm's `tmm-prompt` in the minibuffer: a keymap menu is offered as a copy whose items return their event path, a pane menu as is; a dialog is the menu GNU emulates it with.

# Bundled themes

Romacs themes are palettes (rlisp/romacs-theme.el): each file names a
theme's base colours, and every face is derived from them.

- `default-theme.el`: the stock look a session starts in.
- `omarchy-NAME-theme.el`: the palettes of Omarchy's themes, generated by
  `scripts/import-omarchy-palettes` from Omarchy 9.9.9 (fixture)'s
  `themes/NAME/colors.toml`. Omarchy is MIT-licensed
  (https://github.com/omacom/omarchy, LICENSE); a refresh is a commit of
  the regenerated files.

A palette file uses colors.toml's keys: `mode` (`dark` or `light`),
`accent selection muted background dark_background darker_background
lighter_background foreground dark_foreground light_foreground
bright_foreground red yellow orange green cyan blue magenta brown
bright_red bright_yellow bright_green bright_cyan bright_blue
bright_magenta`, each `"#rrggbb"`.

| theme | mode | palette after | its licence |
|---|---|---|---|
| `omarchy-alpha` | dark | Omarchy's own | MIT (Omarchy) |
| `omarchy-beta` | light | Omarchy's own | MIT (Omarchy) |

Colour values as such carry little or no copyright; the names carry the
upstream projects' goodwill, which the `omarchy-` prefix and each file's
attribution line respect.
